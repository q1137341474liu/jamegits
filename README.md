## Repository Layout

| Folder | Domain | Highlights<sup>†</sup> | Primary Languages |
|--------|--------|------------------------|-------------------|
| `Comp_Arch_works` | Computer Architecture | RISC-V pipeline, cache simulator, branch predictor exploration | C++, SystemVerilog |
| `Computer_Vision_works` | Computer Vision | Image filtering, feature extraction, CNNs in PyTorch & OpenCV | Python (Jupyter) |
| `Digital_IC_Design_works` | Digital IC / ASIC | CMOS cell library, Synopsys DC + ICC2 flow, STA & P&R labs | SystemVerilog, Verilog |
| `FPGA_works` | FPGA Design | Pipelined AES accelerator, VGA game, high-level synthesis demos | Verilog |
| `PCB_works` | PCB / Mixed-Signal | KiCad & Altium boards, Gerbers, fabrication notes | KiCad/Altium, Gerber |
| `Parallel_Programming_works` | Parallel Programming | CUDA, OpenMP, MPI assignments (histogram eq., Floyd-Warshall, etc.) | C, C++, CUDA |
| `Scalar_Vector_GPU_works` | Research Prototype | Scalar–vector GPU micro-arch study (gem5 GPU model mods, micro-benchmarks) | C++, Python |

<sup>†</sup>Each subfolder contains its own source, reports, and (where relevant) simulation data or notebooks.
